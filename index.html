ℹ️ Como Usar a Roleta

1. Cadastro de Participantes: Clique em qualquer círculo de 01 a 60 para colocar o nome e @ do comprador. Tudo é salvo automaticamente no seu navegador.

2. Modo Live no Instagram: Use o botão ⛶ (Tela Cheia) no topo para uma transmissão limpa sem barras do navegador.

3. Opções de Sorteio: Se você vender apenas parte dos números (ex: 45 números), marque "Sortear apenas números comprados" para a roleta nunca cair em número vago!

4. Stories Automático: Ao sair o vencedor, clique em "Baixar Story pro Instagram" para salvar uma arte oficial em alta definição pronta para postar nos stories!

5. Como hospedar no GitHub: Este projeto é 100% estático. Basta subir os arquivos para um repositório no GitHub e ativar o GitHub Pages na aba Settings > Pages!
